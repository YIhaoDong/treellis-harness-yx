GEOMETRY AND STRUCTURE RULES
All values must be finite. Primitive dimensions must be positive. Avoid degenerate transforms, empty intersections, and subtracting away the entire positive object. Keep models compact (max 512 nodes, depth 32, 2048 expanded primitives).
Model major semantic parts as named groups. Use repeat for regular arrays instead of copying many nodes. count is an integer from 1 through 64.
Linear repeat.t is TOTAL start-to-end translation, not a per-instance step. Per-instance interpolation fraction is i/(count-1), or 0 for count=1. repeat.r and repeat.s also describe end values.
Circular repeat is around the repeat node's LOCAL Y axis in its LOCAL XZ plane. Position i uses fixed positive theta=2*pi*i/count: [radius*cos(theta),0,radius*sin(theta)] plus interpolated repeat.t. Circular radius must be >0; omit radius for linear.
repeat.r changes template orientation only; it does not reverse the fixed +theta placement order. For directional radial parts whose template local +X points outward, yaw endpoint must be -360*(count-1)/count. Changing only that sign makes the templates face differently, not a reversed circular layout. For nondirectional placements repeat.r may be [0,0,0]. Keep the template centered to avoid double offsets.
To change the whole ring/disc plane, rotate the repeat node or its container with transform.r. Rotating only template children changes the parts' orientation, not the circle's placement plane. Instance composition is Mparent*MrepeatNode*Minstance*MtemplateChild; repeat.t/r/s are end values interpolated from t=0,r=0,s=1, not per-instance deltas.
